# ACaOS-lab-1

Лабораторная работа №1 по курсу АКиОС.

Скрипт для проверки заполненности директории логов и автоматической ротации: при превышении заданного порога самые старые файлы упаковываются в архив и удаляются из исходного каталога. В репозиторий также входит скрипт, подготоваливающий окружения и тестирующий основной скрипт в пространстве пользователя

## Требования и зависимости

### Для работы основного скрипта `main.sh` в популярных дистрибутивах вроде Ubunty, Debian, Fedora, Arch и т.д. уже предустановлены все необходимые утилиты

### Для запуска тестов `test.sh` дополнительно требуется `fuse2fs`:**
* **Ubuntu / Debian / WSL2:**
  ```bash
  sudo apt update
  sudo apt install -y e2fsprogs fuse libfuse2
  ```

* **Arch Linux**:
    ```Bash
    sudo pacman -S e2fsprogs fuse2
    ```
    (если fuse2fs отсутствует в стандартном пакете, сборка доступна в AUR: yay -S e2fsprogs-fuse)
---
### Использование
```Bash
./main.sh <log_dir> <threshold_percent> <backup_dir>
```
### Параметры

* `<log_dir>` - путь к каталогу с логами для анализа.

* `<threshold_percent>` - целочисленный порог допустимой занятости диска от 0 до 100.

* `<backup_dir>` - путь к каталогу, куда будет помещен архив.
